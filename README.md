# AI Portfolio Optimization

This project builds an AI-based portfolio optimization system using stock market data. It combines machine learning and financial optimization techniques to determine optimal asset allocation.

---

## 🚀 Features
- Fetches stock data using yfinance  
- Calculates returns and covariance matrix  
- Trains a Random Forest model  
- Optimizes portfolio using Sharpe Ratio  
- Visualizes asset allocation  

---

## 🛠️ Tech Stack
- Python  
- pandas, numpy  
- scikit-learn  
- scipy  
- matplotlib  

---

## 📊 Workflow
1. Collect stock data  
2. Compute returns  
3. Train machine learning model  
4. Calculate mean returns & covariance  
5. Optimize portfolio weights  
6. Visualize results
